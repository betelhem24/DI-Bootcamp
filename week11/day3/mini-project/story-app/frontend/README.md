# Week 11 Day 3 - Mini Project: Collaborative Storytelling App

## Project Overview

Full-stack PERN application for collaborative storytelling with JWT authentication.

## Technologies Used

### Backend
- PostgreSQL
- Express.js
- Node.js
- JWT Authentication
- TypeScript

### Frontend
- React 18
- Redux Toolkit
- TypeScript
- Vite

## Features

- ✅ User authentication with JWT
- ✅ Refresh token mechanism
- ✅ Story creation and collaboration
- ✅ Redux state management
- ✅ TypeScript throughout
- ✅ RESTful API

## Installation

### Backend
```bash
cd week11/day3/mini-project/story-app/backend
npm install
npm run dev
```

### Frontend
```bash
cd week11/day3/mini-project/story-app/frontend
npm install
npm run dev
```

## Key Concepts

- Full-stack TypeScript
- JWT authentication
- Refresh tokens
- Redux Toolkit
- PERN stack
- RESTful API design
