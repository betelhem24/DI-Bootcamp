# Week 10 Day 4 - Exercise XP: TypeScript React Components

## Project Overview

React components with TypeScript demonstrating typed props and state.

## Technologies Used

- React 18
- TypeScript
- Vite

## Features

- ✅ Greeting component with typed props
- ✅ Counter with useState and TypeScript
- ✅ UserCard with optional props
- ✅ UserList with useEffect and API fetching

## Key Concepts

- TypeScript interfaces
- Typed props
- Typed state with useState
- Optional props
- API integration with types

## Installation

```bash
cd week10/day4/exercise-xp/exercise
npm install
npm run dev
```
