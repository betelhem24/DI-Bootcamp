# Week 10 Day 2 - Daily Challenge: Age Tracker with Redux Thunk

## Project Overview

Age tracker application demonstrating async Redux operations with Redux Thunk.

## Technologies Used

- React 18
- Redux Toolkit
- Redux Thunk
- Vite
- TypeScript

## Features

- ✅ Async increment/decrement
- ✅ Loading states
- ✅ Error handling
- ✅ Redux Thunk middleware

## Key Concepts

- `createAsyncThunk` for async actions
- Loading state management
- Error handling in Redux
- Thunk middleware integration

## Installation

```bash
cd week10/day2/daily-challenge/challenge
npm install
npm run dev
```

## Project Structure

```
src/
├── age-tracker.tsx    # Main component
├── age-slice.ts       # Redux slice with loading states
├── age-thunks.ts      # Async thunk actions
└── store.ts           # Redux store configuration
```
