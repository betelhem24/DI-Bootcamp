# Week 9 Day 3 - Daily Challenge: Calendar-Based Todo

## Project Overview

Calendar-based todo application with Redux state management.

## Technologies Used

- React 18
- Redux
- Vite
- TypeScript

## Features

- ✅ Add todos by day
- ✅ Edit todos
- ✅ Delete todos
- ✅ Calendar view
- ✅ Redux state management

## Installation

```bash
cd week9/day3/daily-challenge/challenge
npm install
npm run dev
```
