# Week 7 Day 1 - Exercises XP

## Project Overview

This folder contains multiple React exercises demonstrating fundamental concepts including components, props, state management, and event handling.

## Exercises Included

### Exercise 1: Car Component
Basic React component demonstrating props and component composition.

### Exercise 2: Events Component  
Event handling in React including click and keyboard events.

### Exercise 3: Phone Component
State management with `useState` hook.

### Exercise 4: useEffect Component
Side effects and lifecycle with `useEffect` hook.

## Technologies Used

- React 18
- Vite
- JavaScript/JSX
- CSS

## Installation

```bash
cd week7/day1/exercises-xp
npm install
npm run dev
```

## Key Concepts

- Component creation
- Props passing
- State management with useState
- Event handling
- useEffect hook
- Component lifecycle
