# Week 7 Day 3 - Mini Project: Task Management API

## Project Overview

A RESTful API for task management built with Node.js and Express.

## Technologies Used

- Node.js
- Express.js
- JavaScript

## Features

- ✅ Create tasks
- ✅ Read tasks
- ✅ Update tasks
- ✅ Delete tasks
- ✅ RESTful API design

## Installation

```bash
cd week7/day3/mini-project/task-management-api
npm install
npm start
```

## API Endpoints

- `GET /tasks` - Get all tasks
- `POST /tasks` - Create a new task
- `PUT /tasks/:id` - Update a task
- `DELETE /tasks/:id` - Delete a task
